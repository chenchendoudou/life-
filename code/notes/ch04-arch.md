# Ch4 · 处理器体系结构

## 📌 核心概念

- Y86-64 指令集：精简版 x86-64
- 逻辑门、位组合电路、字组合电路
- 存储器件：D 触发器、寄存器、寄存器文件、随机访问存储器
- SEQ 顺序实现：每个时钟周期完成一条指令
- PIPE 流水线：取指 → 译码 → 执行 → 访存 → 写回 → PC 更新
- 冒险（hazard）：数据冒险、结构冒险、控制冒险
- 解决方式：转发（forwarding）、暂停/插入气泡（stall）、分支预测

## 🧠 流水线阶段

```
F → D → E → M → W
```

| 阶段 | 任务 |
|------|------|
| F (Fetch) | 取指令、PC 选择、PC 预测 |
| D (Decode) | 读寄存器、译码 |
| E (Execute) | ALU、CC、br_target |
| M (Memory) | 读/写内存 |
| W (Writeback) | 写回寄存器 |
| 控制冒险 | ret/je/jne 的预测失败处理 |

## 🐛 易错点

1. 转发 ≠ 阻塞；能用转发就别 stall
2. Load-Use 冒险必须 stall 一个周期（因为 MEM 在 E 后才发生）
3. 分支预测失败时需要清空流水线（squash）
4. ret 用栈来预测跳转目标
