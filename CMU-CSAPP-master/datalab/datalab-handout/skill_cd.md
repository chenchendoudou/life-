用户在做 datalab，需要位运算的常用公式，我来系统整理一下，分按运算符归类，方便查。
### 按运算符分类整理，datalab 里直接拿来用

---

### `&`（按位与）

| 公式 | 说明 |
|------|------|
| `x & x = x` | 幂等性 |
| `x & 0 = 0` | 归零 |
| `x & ~x = 0` | 互补相与必为 0 |
| `x & (-x) = 最低位那个1` | 提取最低位的 1 |
| `(x >> n) & 1 = 取第 n 位` | 位提取 |

---

### `|`（按位或）

| 公式 | 说明 |
|------|------|
| `x \| x = x` | 幂等性 |
| `x \| 0 = x` | 不变 |
| `x \| ~x = -1` | 互补相或全 1（-1） |
| `x \| (-x) = 最低位1及以上全1` | `x | -x` 的性质 |

---

### `^`（按位异或）

| 公式 | 说明 |
|------|------|
| `x ^ x = 0` | 相同异或为 0 |
| `x ^ 0 = x` | 与 0 异或不变 |
| `x ^ (-1) = ~x` | 全 1 异或 = 取反 |
| `x ^ y = y ^ x` | 交换律 |
| `x ^ (y ^ z) = (x ^ y) ^ z` | 结合律 |
| `x ^ y = (x & ~y) \| (~x & y)` | 异或展开式 |
| `x ^ y = ~(~(x & ~y) & ~(~x & y))` | 只用 `~` 和 `&` 实现异或 |
| `x ^ (~x + 1) = 0`（当 x=0） | 判断 x=0 的一种方式 |

---

### `~`（按位取反）

| 公式 | 说明 |
|------|------|
| `~~x = x` | 两次取反还原 |
| `~x = -x - 1` | 补码核心恒等式 |
| `~(x + 1) = ~x - 1` | 变形 |

---

### `<<` / `>>`（移位）

| 公式 | 说明 |
|------|------|
| `x << 1 = 2 * x` | 左移一位 = 乘 2 |
| `x >> 1 = x / 2`（近似） | 算术右移 = 除以 2 向下取整（对负数有差异） |
| `1 << n = 2^n` | 构造 2 的幂 |
| `~(1 << 31) = 0x7FFFFFFF = TMax` | 构造 TMax（但注意 isTmax 不让用 <<） |
| `x & (1 << n)` | 判断第 n 位是否为 1 |
| `x >> 31 = 符号位` | 算术右移，正数得 0，负数得 -1 |

---

### 德摩根定律（最常用的转换）

$$
\begin{cases}
x \mid y = \sim(\sim x \mathbin{\&} \sim y) & \text{或 → 与（取反）} \\
x \mathbin{\&} y = \sim(\sim x \mid \sim y) & \text{与 → 或（取反）}
\end{cases}
$$

用来**消掉题目不允许的运算符**，比如 bitXor 就是用它把 `|` 换成 `&`。

---

### 补码核心恒等式（高频考点）

| 公式 | 说明 |
|------|------|
| `-x = ~x + 1` | 补码定义，减法 → 取反加一 |
| `x + (-x) = 0` | 相反数相加必为 0 |
| `TMin + TMin = 0` | TMin 的特殊性：自己加自己也为 0 |
| `~TMin = TMax` | TMin 取反 = TMax |
| `TMax + 1 = TMin` | 溢出回到最小值 |

---

### 符号位判断（常用套路）

| 判断 | 表达式 | 说明 |
|------|--------|------|
| x 是负数？ | `x >> 31` | 结果为 -1（全 1）或 0 |
| x 是非负数？ | `~x >> 31` | 负数取反后符号位翻转 |
| x 和 y 同号？ | `(x ^ y) >> 31` | 同号符号位异或为 0 |
| x 和 y 异号？ | `((x ^ y) >> 31) & 1` | 异号符号位异或为 1 |










取反（`~`）、与（`&`）、异或（`^`）之间有一套非常漂亮的代数关系。我把它们分成**“定义公式”**、**“化简公式”**和**“算术桥梁”**三类，帮你彻底记牢。

### 1. 本质定义（异或怎么由与和取反构成）
异或的本质是“相异为1”，所以它天然由**与**和**取反**组合而成：

> **`a ^ b = (a & ~b) | (~a & b)`**

如果你想把 `|`（或）也去掉，只保留 `~` 和 `&`，可以用**德摩根定律**替换：
> **`a ^ b = ~( ~(a & ~b) & ~(~a & b) )`**

---

### 2. 最常用的简化公式（记住这个，做题飞快）
任何一个位运算表达式，只要把“或”转换成“与和非”，就能化简。异或还有一个极简的等价形式：

> **`a ^ b = (a | b) & ~(a & b)`**

**理解**：`a | b` 找出所有“至少有一个是1”的位，`a & b` 找出“两个都是1”的位。  
用“至少有一个1”减去“两个都是1”，剩下的就是“恰好只有一个1”，即异或。

---

### 3. 与算术运算的桥梁（补码核心）
在二进制补码中，`&` 和 `^` 直接对应着**加法的进位**和**和**：

> **`a + b = (a ^ b) + ((a & b) << 1)`**

反过来，也可以把异或看成**无进位加法**：
> **`a ^ b = a + b - ((a & b) << 1)`**

这个公式极为重要！你之前做的 `howManyBits` 中，`x ^ (x >> 1)` 看似是个“差分”，其实和“无进位加/减”有深层关联。

---

### 4. 代数运算定律（变形的“乘法分配律”）
与（`&`）对异或（`^`）满足**分配律**，这一点很关键：

> **`a & (b ^ c) = (a & b) ^ (a & c)`**

这就好比乘法对加法的分配（`a × (b + c) = ab + ac`），只不过这里是按位“与”分配进“异或”里。

---

### 5. 恒等与特殊关系（帮你快速构造）
这些是推导时的“地基”：
- **与自身的异或**：`x ^ x = 0`
- **与全0的异或**：`x ^ 0 = x`
- **与全1的异或**：`x ^ ~0 = ~x` （即按位取反）
- **与自身的与**：`x & ~x = 0`
- **与全0的与**：`x & 0 = 0`

---

### 6. 最重要的“取反-负数”公式（补码精髓）
在补码机里，取反和负数之间有一条铁律：
> **`~x = -x - 1`**  
> 等价于 **`-x = ~x + 1`**

这条公式解释了为什么你之前算负数映射时，用 `x ^ sign`（`sign` 为全1时）等于 `~x`，因为 `~x = -x - 1`，将负数的符号位全部取反后就得到了它的“反码”。

---

### 总结一张“速查表”

| 公式 | 记忆口诀 |
| :--- | :--- |
| `a ^ b = (a & ~b) \| (~a & b)` | 相异位各自取1 |
| `a ^ b = (a \| b) & ~(a & b)` | 或减与等于异或 |
| `a + b = (a ^ b) + ((a & b) << 1)` | 异或求和，与求进位 |
| `a & (b ^ c) = (a & b) ^ (a & c)` | 与分配进异或 |
| `~x = -x - 1` | 取反等于负一减一 |

这组公式贯穿了绝大多数笔试和底层位运算题，你试试用它们重新推导一遍 `howManyBits`，会发现每一步都有严格的代数依据。😊
