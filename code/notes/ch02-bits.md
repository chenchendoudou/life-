# Ch2 · 信息的表示和处理

## 📌 核心概念

- 位（bit）、字节（byte）、字（word）
- 进制：十 / 二 / 十六进制
- 整数表示：**无符号**与**二进制补码**（two's complement）
- 浮点表示：IEEE 754（单精度 float / 双精度 double）
- 布尔代数与位运算

## 🧠 关键公式

| 项 | 公式 |
|----|------|
| 无符号 UMax | `2^w - 1` |
| 补码 TMin | `-2^(w-1)` |
| 补码 TMax | `2^(w-1) - 1` |
| 不对称性 | `|TMin| = TMax + 1` |
| 浮点 bias（单/双） | 127 / 1023 |
| 单精度规格化值 | `(-1)^s × (1.M) × 2^(E-bias)` |

## 🔑 例题归档

### `isTmax(int x)` — 判断 x 是否为 0x7FFFFFFF

**约束**：仅允许 `~ & ^ | + << >>` 与 `!`，最多 5 个操作符。

**思路 1：Tmax 的相邻模式**
- `Tmax = 0x7FFFFFFF` → `Tmax + 1 = Tmin = 0x80000000`
- `Tmax | Tmin = 0xFFFFFFFF = -1`
- 所以 `x | (x+1) == -1` 当且仅当 `x` 是 `Tmax` 或 `-1`
- 需要排除 `x = -1`：此时 `x+1 = 0`，而 Tmin ≠ 0

```c
int isTmax(int x) {
    int y = x + 1;             // y = Tmin（如果 x 是 Tmax）
    return !(~(x | y))         // 1) x|y == -1
           & !!(y ^ 0x80000000); // 2) y == Tmin (排除 x==-1)
}
```

**思路 2：利用 Tmax 自加溢出的特征**
- `Tmax + Tmax + 1 = -1 + 1 = 0`（溢出回绕）
- 而 `x = -1` 时 `x + x + 1 = -1`，不为 0
- `x = 0` 时 `x + x + 1 = 1`，也不为 0

```c
int isTmax(int x) {
    int s = x + x + 1;          // Tmax 时为 0；-1 时为 -1；其他为非 0
    return !(s | (x + 1))       // s==0 且 x!=-1
           | !(s ^ ~0);         // 或 s 为全 1（x==-1）的反向；通常合并
}
```

**正确版（思路 2 收敛）**：
```c
int isTmax(int x) {
    int s = x + x + 1;            // Tmax → 0；-1 → -1；其他 → 非0
    int notTmin = !!(x ^ 0x80000000); // 排除 x == Tmin
    int isNegOne = !(x ^ ~0);     // x == -1 ?
    // Tmax iff s==0 且 x != -1
    return (!s) & !isNegOne;      // 等价：!(s) & !(x+1^x+1+...) 也可
}
```

**最简常见答案**：
```c
int isTmax(int x) {
    int y = x + 1;
    x = ~x;                          // Tmax → Tmin（仍是 0x80000000）
    return !(y ^ x) & !!y;           // y == ~x 且 y != 0（排除 x==-1）
}
```
- `y == ~x` 当 `x = Tmax`：`y = Tmin`，`~x = Tmin` ✓
- `y == ~x` 当 `x = -1`：`y = 0`，`~x = 0` ✓ 但用 `!!y` 排除
- `y == ~x` 当其他 `x`：通常不相等 ✗

## 🐛 易错点

1. **有符号溢出是 UB 吗？** C 标准说对有符号溢出未定义，但 GCC/x86 上定义为环绕；写可移植代码要避免
2. **无符号 vs 有符号的转换**：位数不变，解释方式变
3. **右移**：有符号是算术右移（补符号位），无符号是逻辑右移（补 0）
4. **浮点 0**：有 +0 / -0 两种
5. **NaN 不可比较**：`NaN == NaN` 为 false

### `floatScale2(unsigned uf)` — IEEE 754 浮点 × 2

**作用**：把 32 位 IEEE 754 单精度位模式 `uf` 表示的数**乘以 2**，返回新的位模式。不允许使用任何浮点运算。

**位字段切分**：
```
| 31 (s, 1位) | 30..23 (exp, 8位) | 22..0 (frac, 23位) |
```

**核心洞察**：在规格化区间内，`(1.frac) × 2^E × 2 = (1.frac) × 2^(E+1)`，所以只需 `exp + 1`，**不动 frac**。

**分情况讨论**：
1. `exp == 0xFF`（NaN / ∞）：原样返回
2. `exp == 0`（非规格化）：`frac` 左移 1（进位会自然落到 exp）
3. `0 < exp < 0xFF`（规格化）：`exp + 1`

**正确实现**：
```c
unsigned floatScale2(unsigned uf) {
    unsigned sign = uf & 0x80000000;
    unsigned exp  = (uf >> 23) & 0xFF;
    unsigned frac = uf & 0x7FFFFF;
    if (exp == 0xFF) return uf;          // NaN / ∞
    if (exp == 0) {                      // 非规格化
        frac <<= 1;
        return sign | (exp << 23) | frac;
    }
    exp += 1;                             // 规格化：exp + 1
    return sign | (exp << 23) | frac;
}
```

**验证样例**：
| 输入 | 值 | 输出 | 值 |
|------|----|------|----|
| `0x3F800000` | 1.0 | `0x40000000` | 2.0 |
| `0x40000000` | 2.0 | `0x40800000` | 4.0 |
| `0xBF800000` | -1.0 | `0xC0000000` | -2.0 |
| `0x00000001` | ≈ 1.4e-45 | `0x00000002` | 翻倍 |
| `0x7F800000` | +∞ | `0x7F800000` | +∞ |
| `0x7F7FFFFF` | 接近上限 | `0x7F800000` | +∞（上溢） |

**关联题**：
- `floatScale64(uf)` → × 64 = × 2^6 → exp + 6
- `floatPower2(x)` → 计算 2.0^x → 直接构造 `exp = x + 127`
- `floatDiv2(uf)` → ÷ 2 → exp - 1（小心下溢到 0）
