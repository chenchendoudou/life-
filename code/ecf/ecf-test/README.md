# ECF 学习示例集（code/ecf/ecf-test）

本目录配合 `code/ecf/` 一起使用，**`code/ecf/` 是 CS:APP 第 8 章"异常控制流"的原始示例代码**；本目录把这些示例按主题重新归类、补上独立的 `csapp.h`，并为每个主题写一份中文导读和原理说明。

> **建议配合阅读**：`code/ecf/` 里的原始程序 + CSAPP 第 8 章教材。

---

## 目录速览

| 目录 | 主题 | 对应 CS:APP 章节 |
|------|------|-----------------|
| `01-syscall-trap/` | **陷阱与系统调用的关系**（反汇编实证） | 8.1–8.3 |
| `02-fork/` | **进程创建**：fork + 9 个思考题 | 8.4 |
| `03-waitpid/` | **进程回收**：waitpid + 思考题 | 8.4 |
| `04-signal/` | **信号**：处理、屏蔽、定时、SA_RESTART | 8.5 |
| `05-setjmp/` | **非局部跳转**：setjmp / longjmp | 8.6 |
| `06-shellex/` | **综合**：一个 100 行的简易 shell | 8.4 + 8.5 |

---

## 推荐学习顺序

1. **01-syscall-trap** — 先在反汇编里亲眼看到 `syscall` 指令，把"陷阱"和"系统调用"的关系钉死
2. **02-fork** — 理解"一次调用，两次返回"和并发
3. **03-waitpid** — 学会清理僵尸子进程
4. **04-signal** — 信号是软件层面的中断，最容易写出 bug
5. **05-setjmp** — 非局部跳转，用于异常处理
6. **06-shellex** — 把所有点串起来

## 编译与运行

```bash
cd /home/xj/chendou/life-/code/ecf/ecf-test
make                # 编译所有示例
make clean          # 清理

# 单独运行
./02-fork/fork_basic
./02-fork/forkprob2
./06-shellex/shellex
```

所有源文件都包含 `../csapp.h`（一个最小化的 CSAPP 头文件替代品），所以**不需要 csapp 那个庞大包装库也能跑**。
